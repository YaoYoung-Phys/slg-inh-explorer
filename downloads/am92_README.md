## 坐标与符号

取 z 为层法向。矩形及四方设置使用 x∥a、y∥b。六方设置使用 a=(1,0,0)、b=(-1/2,√3/2,0)，张量的笛卡尔 y 沿 z×a。因此六方 [010] 不等于笛卡尔 y。

六方操作以明确的晶向表示：C2,[uvw] 为绕该晶向的二重旋转，M_[uvw] 的法向平行该晶向。原文 {x,y,xy} 与 {1,2,3} 两组三元集合分别按 {[100],[010],[110]} 和 {[1 −1 0],[120],[210]} 展开；不依赖原文数字下标逐一对应的未说明约定。

PL_(hkl) 表示相应平面内排除所有特殊轴的方向；GEN 排除全部列出的特殊轴和平面。各分支的样本方向只用于求对应稳定子群，不限制该分支仅含一个方向。

A^ℓ=χ_xyy^ℓ，B^ℓ=χ_yxx^ℓ，采用 χ_abc=−χ_bac 的二维 Hall 张量约定。完整二维张量还满足 χ_xyx=−B、χ_yxy=−A，其他分量为零。

- `+`：同一分量 χ^t=χ^b，局域允许。
- `-`：同一分量 χ^t=−χ^b，局域允许，即 hidden。
- `0`：χ^t=χ^b=0，每层均禁止。
- `v`：同一分量之间无强制比例关系；不排除跨分量关系。

208 个带星号方向还有 A、B 之间的耦合约束，附表给出其完整允许空间。对这些方向，不能只凭两列符号判断两个分量彼此独立。JSON 的 `basis` 使用行顺序 (A^t,B^t,A^b,B^b)，每列为一个独立基向量，系数任意；`dimension` 是该允许空间维数。

## 核验

- 92/92 个目标群通过自旋点群及完整仿射群闭合性检查。
- 774/774 个方向分支的 SOC 点群闭合。
- 774/774 个 MLG 编号具有与参考操作表匹配的仿射变换。
- 774/774 个允许张量空间通过直接三阶张量变换验证，同时独立核对约束矩阵零空间维数，检查允许空间的完整性。
- 2800 个轴、平面和一般方向的样本检验未发现遗漏的稳定子群。
- 最简单 AM 群 8.3.36 的三分支解析结果核验通过：AX_[100] 为 (−,+)，PL_(100) 为 (+,−)，GEN 为 (v,v)。

形式：固定结构与共线磁序，旋转共同磁矩轴；两物理层分处 z=0 两侧。方向可允许并不代表其为磁各向异性能量极小值，也不保证允许的响应实际非零。

报告为 A3 横版，共 40 页。表格按群完整分页，群内前三列合并；208 个耦合分支的完整允许空间列于附表。

## 复算

需要 Python、NumPy、SymPy 和 spglib；PDF 编译还需要 TeX Live 的 pdflatex。

```bash
python -m pip install -r requirements.txt
python calculate.py
python verify_affine.py
python build_report.py
python validate_results.py
pdflatex -interaction=nonstopmode -halt-on-error AM_92_cSLG_Neel_MLG_INH.tex
pdflatex -interaction=nonstopmode -halt-on-error AM_92_cSLG_Neel_MLG_INH.tex
```

原始提取数据与查表索引已提供。如需从附件重新提取或重新建立索引：

```bash
python extract_source.py /path/to/Supplemental_Materials_of_magnetic_stacking_theory.pdf
python identify_mlg.py
```

参考索引没有要求全部 448 条原文记录均能直接映射到三维磁空间群。计算仅将其作为候选筛选工具，最终 774 个结果均以保持层法向的完整仿射操作匹配核验，不以三维编号单独代替 MLG 编号。
